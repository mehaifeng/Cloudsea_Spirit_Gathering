# v0.10 验收清单（2026-10-19 Lynx 试玩反馈四条）

启动：`pnpm dev`（新游戏）。每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **跳下云舟**：新游戏，开场播片不跳过 → 迫降停稳后，镜头转到船身侧面；人走到登船口、蹲一下，跳出船舷，落到草地上扬起一点土，然后镜头转向发光的云气团。全程不会顶着船舷走，也不会突然出现在地上。
2. **商队修船**：打完第一场战斗、关掉结算 → 自动播一段：商队挂旗的云舟落在残骸旁 → 两位伙计跑到残骸两舷敲打（火花、木屑）→ 纸色转场写着“半日后” → 修好的云舟停在码头边，商队云舟飞走 → 回到操作。播片之前残骸一直在原地。
3. **跳过修船**：同上，播片中按 Esc → 直接回到操作，码头边是修好的云舟，商队和伙计都不在了。
4. **池塘位置**：开几次新游戏（不同种子）→ 家园岛池塘都在岛核后面那一半，离码头、迫降的残骸、发光云气团都很远。
5. **不能下水**：朝池塘走 → 走到岸边就停住；斜着走会沿着岸滑过去，不会卡住；跟着的絮灵也不下水。没有游泳动作。
6. **池塘外观**：贴着地面从侧面看池塘 → 水面一直盖到岸上，看不到水面下的坑；岸边一圈石头和几丛芦苇。其他岛（麦浪坡、溪石屿、雾隐谷）的池塘 / 溪流同样，而且都不在登岛栈桥旁边。
7. **栖巢引导**：引导第 4 步建栖巢，让一只絮灵去帮忙建 → 栖巢一建好，引导就跳到“点亮岛核”这一步。
8. **栖巢引导（读档）**：栖巢已经建好、但没让絮灵干过活时 → 引导提示改成“再建一块田地，安排絮灵去打工”；照做后进入下一步。
9. **老存档**：读一个 v0.9 的存档 → 能正常进入；如果原来有建筑落在新池塘的位置，它被挪到了旁边的空地；人不会站在水里。
