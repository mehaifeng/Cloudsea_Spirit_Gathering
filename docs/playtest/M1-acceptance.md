# M1 验收清单（单人垂直切片）

启动：`pnpm install` 后 `pnpm dev`；或 `pnpm build && pnpm --filter @cloudsea/desktop start`。
每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **新游戏**：标题画面输入名字，点“开始新的旅程” → 坠落对话 3 句；家园岛是白天，左上角有“引导”提示，右上角 200 云贝、8 个灯露。
2. **第一只伙伴**：WASD 走几步，找到发光的云气按 E → 云气变成一只晴属性的“暖芽”，冒出爱心；随后一只带黑色粒子的蚀化絮灵冲来，进入战斗。
3. **第一场战斗**：只用“轻击”也一定能赢；能看到伤害数字、血条、云气点数。打完显示经验，回到岛上，引导提示变成“去码头出航”。
4. **出航与捕获**：在码头按 E → 星图 → 麦浪坡；1–2 秒过渡后到岛上，有树、石头、浆果丛和几只野生絮灵在游荡。接触一只，先轻击打到一半以下，再用“灯露” → 捕获成功后它出现在队伍栏（左下角）。
5. **采集**：在树 / 石头前按 E → 屏幕上方提示“+2 木材”等；同一棵树采过后要等一段时间才能再采。
6. **建造与打工**：回家按 B，选“栖巢”放在空地上（红色表示不能放，会提示原因：太陡 / 重叠 / 超出岛的范围）；Tab 菜单里把一只絮灵“离开队伍”，对着栖巢按 E 安排它帮忙 → 进度变快；建好后有提示“栖巢建好了！”。
7. **第一盏灯**：走到岛中央的岛核前按 E → 灯亮、雾散的对话，引导结束。
8. **经营循环**：在码头买晴麦种子，建田地并种下，安排一只晴属性絮灵照料 → 大约一个游戏日（约 20 分钟）后作物自动收进仓库；建工坊做“面粉”；在码头订单板交货得到云贝。
9. **守岛人**：星图去“禾田屿” → 阿禾在麦田边，能聊天、送礼（每天只算一次好感）、比一场；对战中有“认输”，确认后按战败结算；好感 1 级时聊天会触发剧情“第一袋面粉”，拿到繁殖屋蓝图。
9b. **疲惫恢复**：输掉一场后队伍絮灵显示“疲惫”，接触野生絮灵会提示怎么恢复；在码头买“暖心包”，在菜单的絮灵详情里喂它 → 立刻恢复；或者回家园岛待着（有栖巢时约半个游戏日恢复）。
10. **存档**：设置 → 存档并回到标题 → 标题出现“继续：world-xxxx”，点击后回到刚才的位置，絮灵、建筑、云贝都在。

另外请随意看看：夜晚（19:00 以后提灯会亮）、不同天气（雨天有雨丝、风天有飘叶、雾天视野变近）、絮灵详情页（性格、资质、零件、技能、絮灵码）、图鉴里的记忆碎片。
