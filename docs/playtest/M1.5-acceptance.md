# M1.5 验收清单（表现与手感）

启动：`pnpm install` → `pnpm dev`。建议开一个新游戏（旧存档也能读，会自动迁移）。
每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **界面风格**：看标题画面 → 毛笔字标题“云海拾灵”，下方是一张贴着胶带的米色纸片，按钮像盖章（赭红底、硬阴影）。
2. **开场播片**：开始新的旅程 → 上下黑边；一艘失控的云舟冒着烟坠向小岛、撞击时镜头震动，然后镜头转向岛上发光的云气团，最后落回玩家身后。Esc 可跳过。
3. **家园岛**：四处走走 → 岛明显更大（约 60 米），有池塘、小溪、岩坡；水里走不进去；远处能看到星图上的其他浮岛。
4. **动作**：空格跳（跑动中也能跳）；对着树 / 石头 / 浆果按 E → 分别有砍、敲、摘的动作和手里的工具。
5. **尺度**：站到栖巢、工坊、码头旁边 → 人比门矮，建筑有门、坡顶，比例合理。
6. **云舟航行**：码头按 E → 星图选麦浪坡 → 镜头跟着云舟起飞、尾随、侧拍、俯瞰，目的岛由远到近出现，平稳降落，不黑屏。航行中按空格可加速。队伍前 3 只絮灵站在甲板上，其余化成光团绕船飞。
7. **首次登岛 / 首遇**：第一次到一座岛 → 绕岛定场镜头 + 岛名标题卡；第一次碰到野生絮灵 → 镜头推到它的侧脸，字幕“野生的××注意到了你！”。看过的不再播。
8. **初见守岛人**：去禾田屿 → 越肩镜头推到阿禾，她挥手，标题卡写名字与性格；聊天对话框像一张信纸，名字是红色毛笔字。
9. **菜单与战斗**：Tab 打开菜单、絮灵详情；进入战斗 → 都是纸片风格，技能按钮带属性色图标，云气是一排小圆点。
10. **带上絮灵**：在家园岛走到闲着或打工的絮灵身边 → 提示“E 带上 ××”，按 E 后它跳一下、加入队伍并跟着你；队伍里的絮灵按 E 仍是抚摸。

另外请随意看看：夜晚的界面是否仍然清楚；对话时右下角的操作提示会收起。

## 第二轮（DESIGN v0.6，Lynx 第二轮试玩建议）

建议开新游戏（旧存档看不到新开场）。

1. **迫降开场**：开始新的旅程 → 云舟载着你斜着滑向小岛，触地后在草地上犁出一道土痕，你在甲板上跟着摇晃；停住后过两秒你从左舷跳下船，镜头转向岛上发光的云气团（它真的在那里），再回到你身后。
2. **云舟模型**：走近残骸看 → 船底破洞、碎木板支棱出来，甲板以上基本完好；栏杆、桅杆、晶体笼、船头灯、两侧推进舱都连在船上，没有悬空的零件。
3. **首战**：走到云气团前按 E → 对话结束后一只蚀化絮灵从远处冲过来，镜头越过你的肩膀看它跑来、再推到它的侧脸，接着纸色淡出进战斗，战斗镜头从它身边拉回。
4. **战斗行动栏**：按钮更紧凑，按“攻击 → 防御 → 增益 → 治疗 → 其他”分组；鼠标停在按钮上出现说明卡（云气、威力、命中、目标、效果）。
5. **战斗站位**：连续出招十几回合 → 双方每次出招都是向前扑一下再弹回原位，始终面对面，不会走到一起或背对背。
6. **码头与云舟**：在家园岛走上码头（有一级台阶）；往停着的云舟走 → 被船身和推进舱挡住，不会穿进去。
7. **上下船**：码头按 E → 星图 → 选一座岛 → 你走到登船口、跳上甲板，絮灵跟着蹦上来；飞行中镜头一直在船后上方朝向目的地；降落时船悬停掉头停好，你从甲板跳到栈桥上。
8. 〔v0.10 起作废：不能下水，见 `v0.10-acceptance.md`〕~~**游泳**~~：走进家园岛池塘 → 浅处涉水变慢，深处自动切换成游泳（身体前倾、划水），走上岸自动恢复行走；游泳时不能跳、不能采集。
9. **队伍徽章**：左下角是一排小徽章（属性图标 + 名字 + 等级，疲惫的有“疲”字）；点一下打开它的详情；打开菜单、对话时徽章、操作提示和交互提示都会收起。

## 第三轮（DESIGN v0.7，Lynx 第三轮反馈）

建议开新游戏（旧存档看不到新的开场与袭击）。

1. **开场船底**：开场播片里云舟在空中时船底是完好的；触地那一刻木屑飞溅，船底才变成破洞。
2. **首战**：对话结束后，远处一团暗紫色的混沌迷雾翻滚聚拢，蚀化絮灵在雾中由小变大凝聚出来，再冲向你（不会穿过核心塔）；首战对手的血量明显更少。
3. **伤势延续**：打一场野外战斗，故意让絮灵掉血 / 被削弱后逃跑 → 队伍徽章上的血条还是掉着的；再接触一只野生絮灵 → 战斗里生命、增减益、异常都和上一场结束时一样。没有“疲惫”了。
4. **倒下**：絮灵生命打到 0 → 它不能再出战；全队倒下时商队把你送回家园岛，没有别的惩罚。
5. **核心塔治疗**：回家园岛走到核心塔附近（地上一圈光点内）→ 受伤的絮灵身上冒暖色光点，约 10 秒回满，弹出“××恢复了”，增减益与异常一起清除；在家园岛别处也会慢慢恢复；在野外不会恢复。暖心包立刻回满。
6. **核心塔外观**：八角石台、青苔、扶壁、刻着发光符文的三段石柱、石爪托着的拉长光晶和绕着转的碎晶。
7. **上船**：码头按 E → 星图选岛 → 靠码头的一舷放下舷梯（斜度按高差自动调整），你沿舷梯走上甲板，絮灵跟着走上来，舷梯收起，起飞。全程不会撞着船跑、不会被瞬移。
8. **下船**：降落时云舟不再整船掉头；靠栈桥那一舷放下舷梯，你和絮灵沿舷梯走下来。
9. 〔v0.10 起只看水面与泡沫：不能下水〕**水**：走进池塘 → 水面有起伏的小波面，岸边一圈泡沫；身体在水下的部分被染成水色（越深越明显），能看出哪里在水下；游泳和涉水时身边有一圈圈波纹，入水时溅起水花；深处的池底颜色更深。
