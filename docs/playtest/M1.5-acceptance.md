# M1.5 验收清单（表现与手感）

启动：`pnpm install` → `pnpm dev`。建议开一个新游戏（旧存档也能读，会自动迁移）。
每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **界面风格**：看标题画面 → 毛笔字标题“云海拾灵”，下方是一张贴着胶带的米色纸片，按钮像盖章（赭红底、硬阴影）。
2. **开场播片**：开始新的旅程 → 上下黑边；一艘失控的云舟冒着烟坠向小岛、撞击时镜头震动，然后镜头转向岛上发光的云气团，最后落回玩家身后。Esc 可跳过。
3. **家园岛**：四处走走 → 岛明显更大（约 60 米），有池塘、小溪、岩坡；水里走不进去；远处能看到星图上的其他浮岛。
4. **动作**：空格跳（跑动中也能跳）；对着树 / 石头 / 浆果按 E → 分别有砍、敲、摘的动作和手里的工具。
5. **尺度**：站到栖巢、工坊、码头旁边 → 人比门矮，建筑有门、坡顶，比例合理。
6. **云舟航行**：码头按 E → 星图选麦浪坡 → 镜头跟着云舟起飞、尾随、侧拍、俯瞰，目的岛由远到近出现，平稳降落，不黑屏。航行中按空格可加速。队伍前 3 只絮灵站在甲板上，其余化成光团绕船飞。
7. **首次登岛 / 首遇**：第一次到一座岛 → 绕岛定场镜头 + 岛名标题卡；第一次碰到野生絮灵 → 镜头推到它的侧脸，字幕“野生的××注意到了你！”。看过的不再播。
8. **初见守岛人**：去禾田屿 → 越肩镜头推到阿禾，她挥手，标题卡写名字与性格；聊天对话框像一张信纸，名字是红色毛笔字。
9. **菜单与战斗**：Tab 打开菜单、絮灵详情；进入战斗 → 都是纸片风格，技能按钮带属性色图标，云气是一排小圆点。
10. **带上絮灵**：在家园岛走到闲着或打工的絮灵身边 → 提示“E 带上 ××”，按 E 后它跳一下、加入队伍并跟着你；队伍里的絮灵按 E 仍是抚摸。

另外请随意看看：夜晚的界面是否仍然清楚；对话时右下角的操作提示会收起。
