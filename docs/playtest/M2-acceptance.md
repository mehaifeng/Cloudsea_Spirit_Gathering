# M2 验收清单（联机）

启动（同一台电脑两个窗口）：`pnpm install` → `pnpm dev:duo`。
左边是房主（自动开了新游戏并开放了局域网），右边是客人（标题画面已经填好地址）。
每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **加入**：客人窗口点“加入” → 进入房主的世界，出现在自己的家园岛码头；房主窗口弹出“客人 加入了世界”。客人的衣服和围巾颜色和房主不一样。
2. **联机页**：两边按 Tab → “联机” → 都能看到在线 2/4、各自在哪座岛；房主那边能看到本机局域网地址与端口；Steam 一栏没开 Steam 时会说明原因。
3. **互相看见**：两人都去麦浪坡并走到一起 → 能看到对方的人物、头顶的名字、跟着对方的絮灵；对方走路 / 跑步 / 跳跃动作连贯。
4. **合作战斗**：房主接触一只野生絮灵 → 客人走到房主旁边，提示“加入 房主 的战斗”，按 E 进入同一场战斗；场上能看到“房主的 / 客人的”絮灵；每人只能给自己的絮灵选招；一人选好后显示“等待队友选择”和倒计时，都选好才结算。
5. **倒计时**：一人选好后另一人不动 → 30 秒后自动结算（没选的按防御）。
6. **灯塔岛**：星图里多了“晴原灯塔”。两人都去 → 塔下盘踞着放大的、带黑雾的曦冕和两只护卫。
7. **云主战**：一人走近云主按 E“讨伐” → 另一人按 E“加入讨伐” → 位置数 = 人数，云主生命按人数变多；云主每回合出手两次，生命掉到约 2/3 和 1/3 时喊话、换招（第三阶段更凶）。
8. **灯塔重燃**：打赢后两人都得到 300 云贝，弹出“灯塔重燃”；灯塔顶亮起来，曦冕净化后趴在塔边；不能再挑战。输了可以马上重来。
9. **离开与存档**：客人在联机页点“离开（保存角色）” → 回到标题；房主弹出“客人 离开了世界”。客人再点“加入联机”时，角色列表里能看到刚才的角色（絮灵、云贝都还在）。
10. **断线**：直接关掉房主窗口 → 客人提示“联机结束”，回到标题，角色已保存。

另外：如果有两台装了 Steam 的电脑，房主在联机页点“创建房间并邀请好友”，好友在 Steam 里接受邀请会自动加入（开发期用 Valve 的测试 App ID 480）。
