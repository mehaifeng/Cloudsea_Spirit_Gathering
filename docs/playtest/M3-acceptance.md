# M3 验收清单（内容与 AI）

启动：`pnpm install` → `pnpm dev`（新游戏）。想直接看后期进度，可以用测试场景：
`CLOUDSEA_TEST=1 CLOUDSEA_SCENE=chart pnpm dev`（两座灯塔已重燃）、`CLOUDSEA_SCENE=regions`（前四座已重燃）。
每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **星图分页**：按 M → 上方是五个大区页签；没开放的大区写着“浓雾”，翻过去是雾遮罩和“点亮××的灯塔，雾就会散开”；标题显示“第 N 章”。每页的岛都在图框里，不挤不出界。
2. **灯塔守卫**：去晴原灯塔 → 路边站着“灯塔会守卫·麦禾”，靠近按 E 挑战，开战前他说一句话；没打赢他之前，云主的提示是“先打赢灯塔会守卫”。打赢得到云贝和 2 瓶精制灯露，之后才能讨伐云主。
3. **灯塔重燃与开区**：讨伐云主胜利 → “灯塔重燃”对话里说出本区名字，并提示下一区的雾薄了；星图上风谷可以去了；晴原的岛出航不再要燃料（显示“雾已散”），HUD 上的雾浓度变成 0。
4. **五大区**：风谷 / 雨泽 / 雷崖 / 雾海各去一座岛 → 地形、野生絮灵（新物种）不同；雾海的岛雾气明显。
5. **守岛人人设池**：开两个新世界（不同名字） → 晴原都有阿禾、岚；其他大区住的守岛人不同、人数 6–10。去一位新守岛人的岛聊天、送礼、比一场 → 说话风格与他的人设一致；好感升级后能触发他的剧情节点并拿到奖励。
6. **灵性模式**（需要一个兼容 OpenAI 的服务和 key）：设置 → 灵性模式填地址、模型、key → “测试连接”成功 → 打开。和守岛人聊天 → 对话框标“AI 生成”，内容符合人设；点“不合适？屏蔽这句”会关掉且以后不再出现。关掉网络再聊 → 照常说话（回到对话库）。
7. **key 安全**：保存 key 后再打开设置 → key 输入框是空的，只写着“已保存（不显示）”；联机时客人那边的设置页写着“联机时只用房主的 AI 服务”。
8. **岛屿码**：菜单 → 分享 → “生成我的岛屿码” → 复制给自己，粘贴到下面的框里点“参观这座岛” → 进入绕岛参观的画面，建筑、田里的作物和自己的岛一样；Esc 回来。改掉码里一个字符 → 提示“校验失败”。
9. **队伍码**：分享页生成队伍码 → 粘贴后点“挑战这支队伍”（要在家园岛）→ 和自己的同款队伍打一场；打完没有经验、没有云贝，絮灵的伤也不会留下来。
10. **共鸣繁殖**：繁殖屋里选一只雨属性的雌性和一只晴属性的雄性（雨生晴）→ 提示“可以共鸣繁殖：后代是××（随母方）”，能生蛋；选晴和风（不相生）→ 提示“属性不相生”。

自动化：`pnpm test`（含 3 个种子的自动通关）、`pnpm --filter @cloudsea/campaign start --seed 5` 看通关过程。
