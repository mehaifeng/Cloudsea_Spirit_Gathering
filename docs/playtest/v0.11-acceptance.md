# v0.11 验收清单（2026-10-19 Lynx 对 v0.10 的试玩反馈）

启动：`pnpm dev`（新游戏）；直接看修船播片：`CLOUDSEA_TEST=1 CLOUDSEA_SCENE=repair pnpm dev`。每条：做什么 → 应该看到什么。通过后并入 `regression.md`（取代 v0.10 清单的第 1、2、3、6 条）。

1. **跳下云舟**：新游戏，开场播片不跳过 → 人走到登船口，深蹲、双臂往后摆 → 蹬地跳起，手臂往前甩、一条腿提膝，明显高过船舷 → 下落时双腿往前伸 → 落地深蹲一下、扬起尘土，再站起来。不像滑下来的。
2. **商队的船**：打完第一场战斗、关掉结算 → 一艘大船从云里降到残骸旁：两根桅杆挂着带绿色徽记的帆，有船舱、舵轮、货箱木桶，比你的云舟大得多；甲板上站着人（掌舵的、瞭望的）。
3. **前因与商队机制**：大船放下舷梯，领队苏棹走下来和你说话，播片停在两人的镜头上等你翻完 → 讲清楚：灯塔会托商队送货、看见黑烟找来；修船灯塔会付账；每天早上经过码头、订单板、码头买卖、野外全队倒下会被顺路送回家。按 Enter 只翻对话，不会跳过播片。
4. **修理动画**：对话完 → 一个伙计扛着木板、一个捧着工具箱走到残骸旁放下；一个蹲在船边用锤子钉木板，一个弯腰锯木板（没有镐）；领队登上残骸，把一颗发光的晶体举上桅顶，核心重新亮起。
5. **修好、离开**：纸色转场“半日后” → 修好的云舟停在码头边，商队大船升空离开，船上的人挥手 → 回到操作。
6. **跳过修船**：播片中（对话出现之前）按 Esc → 码头边是修好的云舟，领队的对话照样弹出来；翻完就能操作。
7. **池塘**：走到池塘边看 → 水外面没有一圈白色泡沫、沙地或灰色的边，草一直长到水边；只有零散的两三簇芦苇和石头。其他岛的池塘 / 溪流同样。
