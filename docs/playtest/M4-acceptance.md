# M4 验收清单（抢先体验：提交就绪）

启动：`pnpm install` → `pnpm dev`；安装包：`pnpm --filter @cloudsea/desktop dist:win`（产物在 `apps/desktop/release/`，CI 每次推送 main 也会产出并上传）。
每条：做什么 → 应该看到什么。通过后并入 `regression.md`。

1. **成就**：新游戏领到第一只絮灵 → 弹出金色的“成就达成：第一位伙伴”；菜单 → 成就页里它亮着，“幻色”显示为“？？？”。
2. **成就补发**：用旧版本的存档读档 → 已经满足的成就（例如重燃过灯塔）会马上补发。
3. **Steam**（装了 Steam 时）：打开游戏不报错；正式 App ID 配好后，成就会出现在 Steam 覆盖层里（测试 App ID 480 下不会写 Steam 云）。
4. **手柄**：插上手柄 → 左摇杆走（推到底跑）、右摇杆转视角、Ⓐ 交互、Ⓧ 跳、Ⓨ 打开菜单后用十字键选页签、Ⓑ 关闭；屏幕下方的提示换成手柄按键。
5. **手柄战斗**：遇到野生絮灵 → 十字键在招式间移动（会弹出说明卡），Ⓐ 出招，需要选目标时再按 Ⓐ。
6. **切换语言**：标题画面或设置 → 语言 / Language → English → 回到标题，界面全是英文；新游戏里菜单、星图、守岛人对话、战斗也都是英文。切回中文同理。
7. **英文灵性模式**（有 AI 服务时）：英文界面下打开灵性模式，和守岛人聊天 → 他用英文回答，标“AI generated”。
8. **安装包**（在 Windows 上；CI 每次都会自动做一遍静默安装 → 启动开新游戏 → 静默卸载，这里看安装界面和快捷方式）：运行 `CloudseaSpiritGathering-0.1.0-setup-x64.exe` → 安装器有中文界面，可以选安装目录；桌面出现“云海拾灵”快捷方式，图标是浮岛、灯塔和暖芽；启动后标题画面写着 “v0.1.0 · 抢先体验”。卸载后存档留在用户目录。
9. **商店素材**：`pnpm --filter @cloudsea/desktop store-art` → `apps/desktop/screenshots/store/zh|en/` 里各有 7 张 1920×1080 截图和全部尺寸的胶囊图；文案在 `docs/store/`。

需要你本人完成的事（付费 / 账号）：见 `docs/store/README.md` 的清单。
